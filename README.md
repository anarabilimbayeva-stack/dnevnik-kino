# Дневник-кино

Личный дневник, в котором каждый день — разворот тетради и маленький фильм.
Проект для хакатона ArtTech «Make the Invisible Visible».

**Открыть:** https://anarabilimbayeva-stack.github.io/dnevnik-kino/

## Как это работает

Нужны три вещи: рассказ о дне (можно написать, можно надиктовать голосом), фото (или короткие видео) и песня (достаточно названия и исполнителя).

- **Песня решает, как выглядит день.** Сайт слушает файл, находит темп и энергию и по ним выбирает цвет бумаги разворота, наклон фотографий, «пляску» букв-вырезок, длину кадров и резкость склеек в фильме.
- **Текст** даёт название папки дня, подписи-субтитры в фильме и рисунки на полях (волны, солнце, капли, лист, луна, чашка).
- **Фото и видео** становятся полароидами на развороте и кадрами фильма дня.
- **Год** — календарь, где каждый записанный день лежит клочком своей бумаги; нажатие открывает день.
- **Фильм дня** можно сохранить как видео.

Всё работает прямо в браузере: файлы никуда не отправляются, свои дни хранятся на устройстве.

## Файлы

- `index.html` — весь сайт «Дневник-кино» (разметка, стили, код)
- `demo/days-kino.json`, `demo/real/`, `demo/*.mp3` — демо-дни
- `tex/` — бумага, стол и предметы коллажа (скотч, скрепка, лист, записка, марка, билет, чек)
- `kartiny.html`, `app.js` — первая версия проекта («Картины дней»), оставлена для истории

## Инструменты

HTML, CSS, JavaScript без библиотек; Web Audio API (анализ песни), Canvas и MediaRecorder (фильм и запись видео), IndexedDB (хранение дней), шрифты Google Fonts.
Web Speech API (диктовка голосом), открытый каталог iTunes Search (поиск песни и её 30-секундный отрывок).
Демо-фотографии, текстуры бумаги и предметы коллажа сгенерированы нейросетью (Higgsfield), демо-мелодии — тестовые. Код написан с помощью Claude.
